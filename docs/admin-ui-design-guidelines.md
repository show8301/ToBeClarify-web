# 後台 UI 設計規範

更新日期：2026-10-04

本文件記錄清醒夢後台管理介面的共用版面基準。新增或調整後台功能頁面時，優先沿用這裡的間距規則；個別元件的內距與控制項間距可依內容另行調整，但不可取代頁面區塊之間的標準留白。

## 區塊間距基準

目前以「營業工作台」已確認的畫面作為間距基準：

- 垂直區塊間距：`18px`
- 左右並排區塊間距：`18px`
- CSS 變數：`--admin-space-block` 與 `--admin-space-inline`

兩者目前同為 `18px`，分開命名是為了未來若垂直與水平需要不同節奏時，可以只調整設計 token，不必逐頁搜尋固定數值。

## 使用方式

### 垂直堆疊

頁面主要區塊使用 grid 或 flex 的 `gap: var(--admin-space-block)`。例如工作台的指標、出勤卡、主要操作、工作內容與快速入口，都應維持單一 18px 間距。

### 左右並排

兩欄或多欄的功能面板使用 `column-gap: var(--admin-space-inline)`，通常可直接使用 `gap: var(--admin-space-inline)`。營業工作台的「現場待辦」與「包廂服務排程」就是此規則的基準。

### 開發者預覽切換列

開發者帳號顯示「開發者預覽」切換列時，切換列與下方角色工作台內容之間也要保留一個 `var(--admin-space-block)` 的垂直間距，避免切換控制與工作台的第一組統計卡片視覺黏連。這個留白只作用於 `.adminRoleSwitcher.isDeveloperPreview`，不改變切換列內部按鈕的緊湊間距。

### 避免間距疊加

同一層不要同時使用父層 `gap` 和子面板的 `margin-bottom` 來表達區塊間距。當面板放在 grid／flex 容器中時，子面板應使用 `margin-bottom: 0`，由父層 gap 統一控制。

一般文件流頁面若沒有父層 gap，才使用 `.adminPanel` 的 `margin-bottom: var(--admin-space-block)`。

## 服務員工作台指標卡片

採用「主指標放大」版型。桌機四張獨立卡片的寬度比例為 `2:1:1:1`，卡片間距沿用 `18px`；第一張「待處理訂單」為主要指標。

- 每張卡片只保留「主題、數量、說明」三個元素。左側顯示主題與說明，右側顯示數量。
- 主指標主題 `26px`、數量 `22px`、說明 `14px`；其餘卡片主題 `20px`、數量 `18px`、說明 `14px`。主題加粗並使用主要文字色，說明使用次要文字色。
- 所有卡片使用同樣 `14px 16px` 內距與至少 `112px` 高度，內容整組垂直置中。主題列至少 `36px`、說明列至少 `28px`，數量在右側跨兩列置中並靠右對齊；文字可以換行，不使用刪節號隱藏內容。
- 視窗寬度 `1200px` 以下改為等寬兩欄，`560px` 以下改為單欄；仍維持左側文字、右側數量及 `18px` 卡片間距。

此版型套用於 `.adminRoleDashboard-service`，其他角色工作台的指標維持各自既有版型。

## 營業工作台主要操作區

服務員工作台的主要操作依現場流程排列：

- 第一列使用操作卡與包廂服務排程並排；操作卡只顯示「發點餐碼」，不重複說明流程。
- 「現場待辦」獨立佔滿一列，避免與建立點餐碼或包廂排程爭奪注意力。
- 主要操作列與現場待辦之間使用 `var(--admin-space-block)`；列內面板之間使用 `var(--admin-space-inline)`。

所有後台頁面的一般重新整理控制統一使用 `features/admin/shared/AdminRefreshButton.tsx`，固定在視窗右上角、通知浮動按鈕下方，文字為「重整↻」，迴轉符號置於文字之後。定位沿用通知按鈕的安全區與右側 24px 距離；載入或儲存期間依原頁面的停用條件處理，文字維持一致以避免按鈕寬度跳動。保留原有資料更新回呼與草稿保護；錯誤重試與明確標示放棄修改的重新載入操作維持所在區塊，不另建立重疊的浮動按鈕。

## 不屬於本規範的間距

- 面板內距，例如 `.adminPanel` 的 `padding`。
- 標題與說明文字之間的排版距離。
- 表單欄位、按鈕群組、清單列等元件內部的緊湊間距。
- 手機版改為單欄後的內容排序；單欄仍應保留 18px 的垂直區塊間距。

這些屬於元件自身的排版規則，除非造成整體區塊節奏不一致，否則不應直接套用頁面區塊間距。

## 實作位置

- 共用間距 token：`styles/admin/layers/00-foundation.css`
- 一般管理頁面基礎面板：`styles/admin/layers/10-management.css`
- 營業工作台與角色工作台：`styles/admin/layers/50-modern.css`

調整後台頁面時，先確認 CSS 已由 `styles/admin/site.css` 載入，再以瀏覽器的 Computed Style 確認實際 `gap`／`margin` 值為預期結果。字型與 CSS 的本機預覽檢查流程沿用 `docs/local-ui-preview.md`。
