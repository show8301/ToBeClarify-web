# 小費與帳款操作

> 此為先前版本紀錄。分配規則與畫面已改依 [公共小費按工時分配](public-tip-hourly.md)，以下保留舊流程背景。

後台訂單頁的「補登已成交訂單」新增「小費｜員工分配」，支援原營業日出勤員工按人均分、指定一人及自訂比例。小費訂單增加應收，不新增實收；已有收款可關聯既有紀錄，尚未登記則於帳款區「登記收款」選擇原訂單。

「顧客訂單」下方的「訂單小費分配」列出原單連結、分配版本及每人金額；更正需要原因，取代該筆分配並保留歷程，不新增應收或實收。原本包含店家份額時明示全額改分員工的影響。已正式結算的金額由經理重新結算後反映。

帳款區移除新增補登小費，拆成「登記收款」、「登記退款」、「調整應收」，表單類別依入口限制；紀錄顯示應收／實收／退款方向，儲存與作廢前呈現餘額變化。退款不等於減少應收，作廢收款不代表真的退款。

舊版薪資分配放在獨立歷史摺疊區，不混入金流紀錄筆數；保留來源及領取人，可填原因作廢。帳款有未核對的舊小費時顯示提示，不自動補單或抹除舊薪資。核對與發布順序見 API 專案的 `docs/ORDER-TIP-FLOW.md`。

本次修改既有 `AdminOrdersPage.jsx` 僅接入獨立 TSX 元件，未擴大修改該頁，保留原 JSX；新邏輯均使用 TypeScript。需要 API 與 additive migration 後才能完整使用；不屬於純畫面部署。
