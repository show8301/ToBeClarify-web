# 點餐階段 0 操作與發布

Web 發布至 `dev`（https://www-dev.marchgroup.net），API 依專案規定發布 `main`。Web 正式站仍須使用者確認測試站後，再由 dev 推進 main。

1. 經理到「點餐與現場帳款」，填營業日、完整開始／結束日期，儲存每日計畫。跨午夜選隔日結束，不會自動開店。
2. 若要使用階段 0 的新功能，開店前勾選「本營業日使用分項接待及現場帳款」，再按「現在開店」。未勾選則保持原接待／薪資流程。
3. 新模式訂單按餐點數量及每位指名分別接單、開始、完成或取消。每位指名由本人或經理操作；餐點由店員處理。取消後應付與餐點抵用額同步，勿再重複登記折讓。
4. 選顧客後，在「現場帳款」分別登記應付加收／折讓與已發生的實收／實退。入場費需明確登記；不能從開立點餐碼推定已收款。
5. 歸屬不明可先記金額、原因及時間，稍後任何店員均可更正或確認，不要求另一位經理核准。更正會保留舊版本；真的再次收退款須另建紀錄。關店後仍可記錄，未決項目保留分潤。
6. 店員可於工作模式中停止接新單，既有訂單留下協調；新模式須有已核准且時間有效的班表才可被指名。

分項模式的薪資串接尚未開放，不能使用舊計算直接完成結算。完整晚開始、休息緩衝、打卡增減與薪資結算依後續階段提供。本次保留原購買資料，超過預定開始的接單先使用分項改期。

新增介面使用 TSX；原 JSX 頁面僅接入元件與增加狀態展示，保留既有表單，避免此階段同時重寫全部舊流程。所有請求使用同來源 `/api/admin`。

本次按測試環境政策，只執行建置、型別／靜態檢查及部署／HTTP 可用性確認，沒有執行自動化測試或瀏覽器業務流程。
