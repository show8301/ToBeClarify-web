# 結算頁更正計薪職位

經理／開發人員在「出勤核對 → 計薪輸入與人員角色」主要職位旁使用「更正職位」。對話框讀取最新上班職位與資格，顯示原職位、整個營業日的影響範圍，並要求填寫原因。幕後兼任列不提供另一份主要職位更正入口。

更正沿用同源後台 API 與原有權限，由 API 保存原因、前後職位、版本與操作者。正式結算後仍可更正；畫面提示待重算人員，原已結算金額保留，最終步驟須核對全員差額、填寫重新結算原因並確認下一版本。

資料刷新時依較新的職位快照遷移主要輸入，保留尚未保存的分鐘、活動時數與備註，不將舊職位追加回列表造成重複計薪。服務員、經理、指名人員及主要幕後互換均受相同規則處理；幕後兼任與主要幕後合併時只留一列。原工時核准來源由 API 保留。

保存已成功但刷新失敗時，只提供重新讀取，避免重送已完成的更正。預期快照版本防止覆蓋另一位經理的較新更正；遇版本衝突可重新讀取後核對。

依賴 API 專案的 `docs/PAYROLL-ROLE-CORRECTION.md` 所述契約。手動回歸：`node --experimental-strip-types --test tests/settlement-role-refresh.test.mjs`。本功能測試不加入 dev 部署自動化套件。
