# 全站原生下拉選單設計標準

更新日期：2026-10-09。適用公開網站、顧客點餐與後台的原生單選 `<select>`。

## 標準外觀：方案一

- 單一向下箭頭，SVG 尺寸 16 × 16px，距右側 14px，垂直置中；不增加圖示底色、分隔線或另一個箭頭。
- 欄位至少 44px 高，右側內距 44px，避免文字與箭頭重疊。
- 隱藏原生箭頭，但保留原生選單、整個欄位點擊、鍵盤操作、標籤、焦點提示及 disabled 行為。
- 顏色、邊框、圓角、字級與左側內距依所在頁面保留；本標準統一的是箭頭與操作空間，而非強制所有主題相同。
- 多選、`size` 大於 1 的列表不套用；高對比模式恢復系統箭頭。特殊控制如需保留原生外觀，可加 `data-native-select`，並記錄例外原因。

## 實作與新增頁面

唯一箭頭來源為 [styles/shared/select.css](../styles/shared/select.css)，由 public、admin、ordering 三個樣式入口最後匯入。不要另複製 SVG、添加圖示節點或逐頁設定箭頭位置。

共用 selector 排除多選、列表及原生外觀例外，優先度高於既有各頁背景 shorthand，避免其清除箭頭；不使用 `!important`。新增樣式請使用 `background-color` 修改底色，避免新增更高優先度的 `background` 或箭頭覆寫。

## 盤點與驗證

目前包含訂單查詢／管理、包廂、值班、出勤結算、店員、菜單、首頁設定、通知、留言、作品交付及顧客點餐的單選欄位，也涵蓋共用 CSS 的預覽頁。通知廣播店員／角色的 `multiple` 清單保留列表外觀。

變更只涉及 CSS，不改 API、選項值、權限與表單事件。交付前依 [本機 UI 預覽流程](local-ui-preview.md) 檢查 CSS、字型、明暗主題、手機、長文字、焦點與停用狀態；未取得實際瀏覽器渲染時須明確標示尚未視覺驗證。
