# 結算設定：查看及選用規則

入口為結算工作臺 `/admin/settlement?businessDate=YYYY-MM-DD&sessionNo=1&tab=settings`。

- 上方「本營業日使用的規則」顯示目前採用的版本，已結算時標示為正式結算快照。
- 「已儲存的規則版本」列出版本生效日、日期類型及短 ID，可切換查看完整時薪及分潤，查看不會修改結算。
- 建立成功後立即更新版本清單並顯示新版本；儲存結果不確定時可重新讀取列表核對，避免誤以為資料遺失。同類型／同生效日的重複建立由 API 拒絕。
- 「選用此規則」只設定待套用版本。未正式結算者至營運結算保存輸入並重新計算；已正式結算者於最終步驟預覽並由經理填原因建立新版。可以取消待套用規則。
- 手動選用生效日晚於營業日的版本時顯示歷史補正提示。跨日期類型需選擇相符規則。
- 重新結算預覽列出原／新規則 ID 與生效日；確認成功後才更新目前採用版本，原規則留在歷史快照。

需要同批 API 的 `ruleVersionId` 選用契約；不需要 migration。Web 仍先 dev、經使用者確認後再以 dev → main 推進。
